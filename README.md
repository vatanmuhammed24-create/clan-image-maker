# ClanForge - Clan Image & Banner Generator

A modern, fast, client-side web application for creating custom clan banners, player cards, Discord avatars, and esports graphics in seconds.

## ✨ Features

- **Format Presets**:
  - Discord Avatar (600x600, 1:1)
  - Clan Banner (960x540, 16:9)
  - Player Roster Card (800x1100, Portrait)
  - Twitter/X Header (1200x400)
  - Full HD Wallpaper (1920x1080)
- **Clan Customization**:
  - Clan Tag, Clan Name, Player Name, Role/Rank, Motto
  - Gaming fonts (`Orbitron`, `Rajdhani`, `Teko`, `Inter`)
  - Dual-color neon glow system
- **Graphics & Badges**:
  - Built-in vector emblems: Shield, Crossed Swords, Skull, Crown, Crosshair
  - Custom Clan Logo upload (transparent PNG support)
  - Custom Wallpaper / Screenshot upload with adjustable darkness & vignette
- **Frame & Visual FX**:
  - Cyber brackets, double military, or neon outline borders
  - Hex grid and tech grid patterns
  - Cyberpunk scanlines and film grain effects
- **One-Click Export**:
  - Instant high-res **Download PNG** & **Download JPG**
  - **Copy to Clipboard** for pasting straight into Discord (`Ctrl + V`)
